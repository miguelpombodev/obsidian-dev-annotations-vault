The SOLID principles are five essentials guidelines that enhance software design, making code more maintainable and scalable.

The SOLID principles help in enhancing loose coupling. Loose coupling means a group of classes are less dependent of each other. 
And also helps in making code more reusable, maintainable, flexible and stable.
Loosely coupled classes minimize changes in your code when some changes are required in some other code.
